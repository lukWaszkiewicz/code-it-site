# code-it-site

Company website of Code-it Łukasz Waszkiewicz, served at https://code-it.info by GitHub Pages from `master`.

Static HTML and CSS only — no build step, no cookies, no trackers, no external fonts or scripts.

| Path | Page |
|---|---|
| `index.html`, `privacy.html` | English |
| `pl/index.html`, `pl/privacy.html` | Polish |
| `assets/` | Stylesheet, favicon and portrait photo |
| `assets/clients/` | Client logos (Wikimedia Commons; Elli from elli.eco), shown greyscale on white tiles |

Keep the English and Polish pages in step: every content change goes into both.
The product site lives in `lukWaszkiewicz/releaseguard-site` (https://releaseguard.code-it.info).
